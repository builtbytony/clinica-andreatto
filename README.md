# Clínica Andreatto

Landing page for Clínica Andreatto, Estética Avançada, Rio Branco, AC.

Single self-contained `index.html` (HTML, CSS and JS inline). No build step.

## Before going live
- Replace image placeholders (search for `SUBSTITUIR`).
- Fill credentials, address and hours (search for `PREENCHER` and `a confirmar`).
- Update `canonical` and `og:url` to the real domain.
- Add GA4 / Meta Pixel IDs in the commented blocks in `<head>`.
- Promo section `#condicoes` hides itself after its `data-expires` date.
